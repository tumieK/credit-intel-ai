# credit-intel-ai
South African individuals and SMEs with informal or irregular income struggle to access credit due to rigid, document-heavy assessment systems. This platform uses AI to analyse unstructured financial documents and generate explainable credit risk insights for lenders.

# AI-Powered Credit Intelligence Platform

An AI-driven platform designed to assist South African lenders in assessing credit risk for individuals and SMEs with informal or irregular income.

## Key Features (Planned)
- Secure authentication and role-based access
- AI-powered document analysis
- Explainable credit risk scoring
- Analyst and client dashboards
- Payment and subscription support
- Audit logging for compliance

## Tech Stack
- Backend: FastAPI (Python)
- Frontend: Next.js (TypeScript)
- Database: PostgreSQL
- AI: LangChain, LLMs, Vector DB
- Payments: Stripe / Paystack
